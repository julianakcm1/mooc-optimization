# mooc-optimization

## Sobre o problema

Dado um orçamento limitado de intervenções por semana, este projeto busca selecionar dinamicamente em quais alunos intervir e qual intervenção aplicar para maximizar a retenção ao longo de um MOOC.

## Dataset

O dataset utilizado neste projeto está disponível no Kaggle: <https://www.kaggle.com/datasets/sst2023/kdd-cup-2015>
